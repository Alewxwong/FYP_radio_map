##  1. Project Overview

Radio Environment Maps (REMs) are spatial representations of wireless signal strength across a geographic area. They are essential for 5G/B5G network planning, access-point placement, and coverage optimization. 

Traditionally, generating high-fidelity radio maps requires computationally expensive Ray Tracing (RT) simulations (e.g., Sionna RT, WinProp), which are too slow for real-time interactive planning. While standard Deep Learning models (like U-Net) offer fast predictions, they often over-smooth sharp signal transitions (diffraction edges and shadow boundaries), leading to inaccurate "dead zone" predictions.

### 🚀 Our Solution
This project proposes a novel **2-Stage Physics-Unrolled Neural Operator** architecture adapted for outdoor urban environments. Instead of treating radio maps as generic images, our model explicitly decomposes wireless propagation into physical mechanisms:
*   **Stage 1 (Global Specular/LoS):** Uses a Fourier Neural Operator (FNO) combined with a Local Convolution branch to capture broad Line-of-Sight coverage and large-scale reflections efficiently.
*   **Stage 2 (Diffraction-Aware Refinement):** Uses a specialized block with **Dilated Convolutions** and **SDF Edge-Gating** to sharpen signal drops at building corners and shadow boundaries.
*   **Multi-Fidelity Fine-Tuning:** Automatically transitions from intermediate-fidelity (IRT2) to high-fidelity (IRT4) labels to "snap" blurry corners into sharp, high-fidelity edges.

By leveraging the large-scale RadioMapSeer dataset and physics-aware loss functions, our model achieves high-fidelity signal strength predictions in milliseconds.

## 🏗️ 2. Methodology & Architecture

### 2.1 Input Features (5-Channel Geometry Priors)
To ground the neural operator in physical reality, we do not just feed raw building masks. We compute and stack 5 explicit geometry prior channels:
1.  **Building Mask:** Binary map of urban structures (1 = Building, 0 = Free Space).
2.  **Antenna Heatmap:** Gaussian blob indicating the Transmitter (Tx) location.
3.  **SDF (Signed Distance Field):** Normalized distance from every pixel to the nearest building wall (crucial for identifying diffraction zones).
4.  **Tx Distance Map:** Euclidean distance from the transmitter to every pixel.
5.  **LoS/Shadow Mask:** Ray-casted binary mask indicating shadowed regions.

### 2.2 The 2-Stage Cascade
*   **Stage 1 (FNO + Local Branch):** 
    *   *FNO Path:* Uses Fast Fourier Transforms (FFT) to capture long-range global dependencies and smooth LoS propagation.
    *   *Local Path:* Uses standard 2D Convolutions to preserve localized spatial details that FFT might blur.
*   **Stage 2 (Diffraction-Aware Refinement Block):** 
    *   Takes the Stage 1 output and concatenates it with the geometry priors.
    *   Uses **Dilated Convolutions** to expand the receptive field and trace long shadow lines behind buildings.
    *   Uses an **SDF Edge-Gate** to mathematically force the network to apply corrections *only* near building boundaries.
    *   *Final Output = Stage 1 Prediction + Stage 2 Residual.*

### 2.3 Physics-Aware Loss Functions
Standard MSE loss causes blurry predictions. We use a composite, deployment-oriented loss:
*   **Shadow-Aware Huber Loss:** Dynamically multiplies the loss by a weight map that penalizes errors 3x–4x more heavily in shadow regions (`LoS == 0`) and near building edges (low SDF values).
*   **Sobolev Gradient Loss:** Penalizes mismatches in the spatial gradients (edges) of the prediction, forcing the model to preserve sharp shadow boundaries.

## 🗂️ 3. Dataset & Preprocessing

We utilize the **RadioMapSeer** dataset, which contains 700 urban maps with 80 transmitter locations each (56,000 total samples).

### Multi-Fidelity Training Strategy
*   **Phase 1 Training Label (Intermediate-Fidelity):** `IRT2` (Image-based Ray Tracing with 2 interactions). Provides enough data for the model to learn complex physics without overfitting.
*   **Phase 2 Fine-Tuning Label (High-Fidelity):** `IRT4` (4 interactions). The Stage 2 training loop automatically switches to IRT4 for the final 10 epochs with a lower learning rate to sharply refine the building corners.
*   **Data Normalization:** Raw PNG targets (0-255) are normalized to `[0, 1]` during preprocessing.
*   **Storage:** Data is compressed and stored in **HDF5 (`.h5`)** format for ultra-fast PyTorch data loading and minimal RAM usage.

## ▶️ 6. How to Run

Once the environment is activated and the data is in place, you can run the pipeline:

### Step 1: Data Preprocessing
Parse the `dataset.csv` and generate the `.h5` files with geometry priors.
```bash
python data_process.py
```
*(Note: This will generate `radiomapseer_multifidelity_train.h5`, `val.h5`, and `test.h5` in the `processed_data/` folder. It uses multiprocessing and may take 1-2 hours depending on your CPU.)*

### Step 2: Train Stage 1 (FNO + Local Branch)
Trains the global specular and LoS prediction model. Includes auto-resume checkpointing.
```bash
python train_stage1.py
```

### Step 3: Train Stage 2 (Diffraction-Aware Refinement)
Freezes Stage 1 and trains the residual refinement block. **It will automatically switch to IRT4 fine-tuning at Epoch 20.**
```bash
python train_stage2.py
```

### Step 4: Inference & Visualize
Run the inference script on the Test set to generate side-by-side visual comparisons and calculate metrics.
```bash
python inference.py
```

## 📊 7. Evaluation Metrics

Unlike standard computer vision tasks, radio map accuracy must be evaluated based on wireless deployment needs. We track:

*   **RMSE & MAE (in dB):** Measures average pixel-wise path gain error. Calculated and reported in **decibels (dB)** to allow direct, fair comparison with academic literature (e.g., PU-HNO, RadioUNet).
*   **Outage Recall:** The percentage of actual "dead zones" (signal < threshold) correctly identified by the model.
*   **Outage F1 (Dice Score):** The harmonic mean of Precision and Recall for coverage holes. 

**Why this matters:** A model can have a low RMSE by predicting a smooth, blurry map, but it will completely miss sharp coverage holes. **Outage F1 is our primary metric for success.**
